## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Java-Initial.git
```

2. Navigate to the project:

```bash
cd Java-Initial
```

3. Compile a Java program:

```bash
javac FileName.java
```

4. Run the program:

```bash
java FileName
```
